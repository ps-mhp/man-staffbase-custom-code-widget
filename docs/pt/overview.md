# Código personalizado

O widget de código personalizado não exibe nada por si só. Na página, é
invisível e não ocupa espaço — apenas contém o código que foi
introduzido na caixa de diálogo de configuração:

- O **CSS** é carregado globalmente na página e, por isso, aplica-se a toda a
  página, não apenas ao contentor do widget.
- O **JavaScript** é executado com acesso à página e pode alterá-la
  conforme desejado.

Este widget é adequado para tudo o que não é possível
alcançar através dos recursos padrão do CMS: formatações especiais, pequenas interações, o
exibição ou ocultação de elementos.

> Por este motivo, esta página de documentação **não inclui nenhum exemplo ao vivo**
> — caso contrário, o código inserido seria executado nesta própria página em vez de
> na página de destino real.
