# Custom-Code

Das Custom-Code-Widget stellt selbst nichts dar. Auf der Seite ist es
unsichtbar und belegt keinen Platz — es trägt nur den Code, der im
Konfigurationsdialog eingegeben wurde:

- **CSS** wird global in die Seite geladen und gilt damit für die ganze
  Seite, nicht nur für den Widget-Container.
- **JavaScript** läuft mit Zugriff auf die Seite und kann sie beliebig
  verändern.

Das Widget eignet sich für alles, was über die Bordmittel des CMS nicht
erreichbar ist: Sonderformatierungen, kleine Interaktionen, das gezielte
Ein- oder Ausblenden von Elementen.

> Aus diesem Grund bettet diese Dokumentationsseite **kein Live-Beispiel**
> ein — der hinterlegte Code liefe sonst gegen diese Seite selbst statt gegen
> die eigentliche Zielseite.
