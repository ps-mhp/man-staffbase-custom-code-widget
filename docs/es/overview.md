# Código personalizado

El widget de código personalizado no muestra nada por sí mismo. En la página es
invisible y no ocupa espacio; solo contiene el código que se ha introducido en el
cuadro de diálogo de configuración:

- El **CSS** se carga de forma global en la página y, por lo tanto, se aplica a toda la
  página, no solo para el contenedor del widget.
- El **JavaScript** se ejecuta con acceso a la página y puede modificarla
  como se desee.

El widget es adecuado para todo aquello que no se pueda
lograr con los recursos propios del CMS: formatos especiales, pequeñas interacciones, la
aparecer o desaparecer de forma selectiva.

> Por este motivo, esta página de documentación **no incluye ningún ejemplo en vivo**
> — de lo contrario, el código almacenado se ejecutaría en esta misma página en lugar de en
> la página de destino real.
