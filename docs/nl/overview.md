# Aangepaste code

De widget ‘Aangepaste code’ geeft zelf niets weer. Op de pagina is hij
onzichtbaar en neemt hij geen ruimte in — hij bevat alleen de code die in het
configuratievenster is ingevoerd:

- **CSS** wordt globaal in de pagina geladen en geldt dus voor de hele
  pagina, niet alleen voor de widgetcontainer.
- **JavaScript** draait met toegang tot de pagina en kan deze naar believen
  wijzigen.

De widget is geschikt voor alles wat niet via de standaardfuncties van het CMS
kan worden gerealiseerd: speciale opmaak, kleine interacties, het gericht
weergeven of verbergen van elementen.

> Om deze reden bevat deze documentatiepagina **geen live voorbeeld**
> — de opgeslagen code zou anders tegen deze pagina zelf draaien in plaats van tegen
> de eigenlijke doelpagina.
